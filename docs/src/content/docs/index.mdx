## What evault gives you

<CardGrid stagger>
  <Card title="OS-native secret storage" icon="seti:lock">
    Secrets live in Windows Credential Manager, macOS Keychain, or Linux
    Secret Service — never on disk in plaintext, never on the network.
  </Card>
  <Card title="Encrypted metadata at rest" icon="seti:db">
    Variable names, lengths, and timestamps are persisted in a SQLite
    database that can be encrypted at rest with SQLCipher and a 256-bit
    master key generated on first run.
  </Card>
  <Card title="Per-project manifests" icon="document">
    A declarative <code>evault.toml</code> binds variables to projects with
    profiles for dev / staging / prod. Values stay central; only references
    live in the project tree.
  </Card>
  <Card title="Inject without writing .env" icon="rocket">
    <code>evault run</code> spawns a child process with the resolved
    environment overlay applied directly — no <code>.env</code> file ever
    touches disk.
  </Card>
  <Card title="Interactive TUI" icon="laptop">
    A ratatui-based dashboard with CRUD, link-to-project, view-value,
    fuzzy filter, error modals, and inline command execution.
  </Card>
  <Card title="Source-code scanner" icon="magnifier">
    Walk a project tree and classify every variable reference as orphan,
    unused, or referenced — across JS/TS, Python, Rust, Go, and Shell.
  </Card>
</CardGrid>
