> `.env` file generator that satisfies [`evault-core`](https://crates.io/crates/evault-core)'s `Materializer` trait — atomic writes, a "do not edit" header, and automatic `.gitignore` management.

`EnvFileMaterializer` writes a `KEY=VALUE` file with a `# Generated by evault — do not edit` header, ensures the parent directory exists, and updates the sibling `.gitignore` so the output's basename is ignored by git.

## Safety properties

- **Atomic**: writes go through a tempfile sibling then `fs::rename`. A crash or out-of-space mid-write never leaves a partial `.env` visible at the target path. The tempfile lives in the same directory, keeping the rename on a single volume (a requirement for atomicity on Windows).
- **Restrictive permissions**: on Unix the tempfile is created with mode `0o600` so the resolved secret values are readable only by the owning user. On Windows the file inherits the directory's ACL.
- **Durable**: the tempfile is flushed via `sync_all` before `rename`, so a power loss between rename and writeback cannot leave the new file empty on next boot.
- **Injection-rejecting**: values containing CRLF or NUL bytes are rejected before any disk write.

## Install

```toml
[dependencies]
evault-core = "0.1"
evault-materializer = "0.1"
```

## Example: write a `.env` from a resolved environment map

```rust
use std::collections::BTreeMap;
use evault_core::traits::Materializer;
use evault_materializer::EnvFileMaterializer;

let dir = tempfile::tempdir().unwrap();
let path = dir.path().join(".env");

let mut env = BTreeMap::new();
env.insert("NODE_ENV".to_string(), "production".to_string());
env.insert("DATABASE_URL".to_string(), "postgres://localhost".to_string());

EnvFileMaterializer::new()
    .materialize(&path, &env)
    .unwrap();

let body = std::fs::read_to_string(&path).unwrap();
assert!(body.contains("NODE_ENV=production"));
assert!(body.contains("DATABASE_URL=postgres://localhost"));
```

After this runs, `<dir>/.gitignore` exists (or has been updated) so that `git status` will not show `.env` as untracked.
